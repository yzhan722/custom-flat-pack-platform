# Custom Flat-Pack Furniture Platform

AI、参数化设计与数字制造驱动的定制板式家具项目。

当前阶段：方向验证与 Pre-PRD。当前结论为 **Conditional Go**：先用一个城市、一个生产流程、两种柜体模板和一套材料／五金体系完成小规模付费验证，再决定是否扩大软件与制造网络投入。

## 建议的验证顺序

1. 冻结首发客户、用途、产品边界及服务区域。
2. 同时进行真实客户报价、实物样件加工和非专业用户组装测试。
3. 记录前 10 单的完整工时与成本，并累计观察至少 30 单。
4. 只有需求、工程和单位经济同时通过，再把重复人工流程产品化。

## 重要边界

这些文档不是可直接投入生产的工程图或安全认证。板材、五金、连接、荷载、稳定性、制造公差、包装和固定方案必须根据实际设备、供应链、适用要求和实物验证后发布。
